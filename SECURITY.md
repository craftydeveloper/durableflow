# Security policy

## Reporting a concern

Please do not publish details of an unpatched security issue. Open a private security advisory through the repository's security reporting flow, including affected versions, impact, and a minimal reproduction. Do not include real personal or research data.

## Scope

This repository is an early-stage technical foundation. The local API has no authentication and uses in-memory storage. Do not expose it to untrusted networks or use it for sensitive data until access control, durable storage, validation, and operational safeguards are implemented and reviewed.
